EVER Integration Layer

Prototype of the layer between the legacy branch POS (Point of Sale) and SAP Business One for the three pilot branches. A built-in simulator plays the branch sync agents and the ERP (Enterprise Resource Planning) system, so every test case from the document can be run here.

loading
Prototype notice. This page runs a working prototype that imitates the MuleSoft Anypoint integration layer described in the project document. It is written in Node.js and is not MuleSoft. It does not run on MuleSoft's platform and none of its flows are Mule applications. It runs the same behavior (gateway, queue, transformation, retry, dead-letter queue) so the design can be demonstrated and tested without a MuleSoft licence. The ERP is a mock of the SAP Business One Service Layer, the branch agents are simulated, data is kept in memory and resets when the service restarts, and no real EVER data, systems or credentials are used.
