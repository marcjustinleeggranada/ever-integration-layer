Prototype notice. This page runs a working prototype that imitates the MuleSoft Anypoint integration layer described in the project document. It is written in Node.js and is not MuleSoft. It does not run on MuleSoft's platform and none of its flows are Mule applications. It runs the same behavior (gateway, queue, transformation, retry, dead-letter queue, review queue) so the design can be demonstrated and tested without a MuleSoft licence. The ERP is a mock of the SAP Business One Service Layer, the branch agents are simulated, data is kept in memory and resets when the service restarts, and no real EVER data, systems or credentials are used.
